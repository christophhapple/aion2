# Server and faction transfers

Researched 2026-10-20. Main sources are the two official NC notices [359][360] (both updated 2026-10-20),
so the rules below are official unless tagged otherwise. Not tried in-game.

## Faction transfer
- **Doesn't exist.** Server transfers only go to servers of the **same faction** [360]. No faction or
  race change service is offered or announced; guides agree [361][362].
  The only way to the other side is a new character on a server of that faction.
- Instanced content (dungeons) is cross-server, so same-faction friends on other servers can still run
  dungeons together; open world, Market and Legion need the same server (guide [361], unverified).
- **Instanced matchmaking seems to mix factions** (in-game 2026-10-20). The Expedition room list shows
  leaders from Elyos *and* Asmodian servers side by side (SIE, FRE, HIT next to BAB, ZEM, ULG), and a
  Battlefield team had both too (VAI, SIE, NEZ, NAN next to LUM, BAB, ISR, ZIK). Which tag is which faction comes
  from the server pair list [363] (guide), so that part is unverified.
- **Room Settings → Faction: "All" (default) or "Same Faction"** (in-game 2026-10-20). So Expedition rooms
  are cross-faction unless the leader restricts them. The room list's **"My Faction"** checkbox presumably
  filters for "Same Faction" rooms. Ticking it showed no rooms at all, so hardly anyone sets it (inference).
  Still open: can you party with or friend someone from the other faction directly, outside the room
  list? ~~Elyos and Asmodians can't group anywhere~~ (Claude's own assumption 2026-10-20, contradicted by this).

## Server transfer, autumn 2026 window
- **Which servers when** [359][360]:
  - Early Access servers: 2026-10-14 → before maintenance 2026-10-21 (only to other Early Access servers).
  - **Launch servers: after maintenance Wed 2026-10-21 → before maintenance Wed 2026-10-28.**
    **Nania is a Launch server** (paired with Hadala) (guide [363], unverified), so its window is this one.
- **Hours (Europe):** daily **12:00–16:00 and 18:00–22:00 CEST/CET** [359][360]. On 2026-10-21 the first
  round starts at **14:00** (after maintenance). The last day is presumably 2026-10-27, since the window
  closes before the maintenance on 2026-10-28 (inference).
- **Where:** In-game Shop → Server Transfer [360].
- **Cost:** free (0 Quna base + 0 per character). Only extra character slots on the destination cost
  1,000 Quna each [360]. Fine for F2P.
- **Limits:** **once per account** for the whole period, one source server → one destination server, any
  number of characters in that one go. **Can't be cancelled or undone** [360]. Each server has an
  in/out capacity, updated every hour on the hour; a full server can't be left or joined [359].
- **Same region** only (EU → EU) [360]. NC says it may sell transfers again later [360].
- **Creation lock ≠ transfer lock:** Nania showed **"creation restricted"** for new characters (in-game
  2026-10-23). Guides name transfer as the workaround: create on an open same-faction server, then transfer
  in [425] (guide, unverified). Whether a creation-locked server still accepts transfers depends on its
  inbound capacity in the transfer window (not checked).

### Requirements per character [360]
- Level 10+, standing in a **village** (not Abyss, Spacetime Rift or a dungeon).
- **Not in a Legion**, no pending Legion application.
- **No active Duty Missions.**
- Nothing unclaimed: no Market listings, unsold items or uncollected proceeds; Shop Storage empty
  (incl. Founder's Pack); no unread mail on that character.

### What moves [359][360]
- **Moves with the character:** level, gear, inventory (Cube), **Character Storage** (incl. bought slots),
  Kina in inventory + Character Storage, Abyss Points, skills/Stigmas, Daevanion, quests, exploration, Monolith +
  Empyrean Traces, Wings, Arcana, Pantheon, Theostones, crafting/gathering/Substance Morph records,
  attendance, friends + block list (names update), skins/customization.
- **Content counters move too:** cube reward counts, pity counters, content tickets, Abyss time, Rift
  time, corridor use, Supply Requests, Season Missions + claim history, Season Rank Points (removed on the
  old server). Corridor only if your faction holds it on the new server.
- **Server-wide progress** (Daily Dungeon, Shugo Festival, Invasion rewards) is carried over *and*
  stays on the old server too.
- **Merged** with the destination (and removed from the old server): titles (server-based ones), achievements (higher progress
  wins for server-based ones), closet skins, pets, Genus Crystals, Quna, Mileage, membership.
- **Genus Insight:** pick either the old or the destination server's progress; the old one is reset
  either way.
- **Doesn't move:** **Server Storage contents (and Kina in it)**: move them to the character first. The
  expansion count does carry (higher of both). **Mail block list.** Bought character slots stay on the old server.
- **Name:** always becomes "@TemporaryName"; pick a new one on first login, the old one only if it's free there.
- Shop purchase limits: character-based ones carry over; for server-based coin shop limits the higher
  count of both servers applies (no extra buys). During the period, Soul Crystals and Instant Clear
  Tickets (Server) aren't sold by the Wind Breeze Merchant (same amounts via Substance Morph), and the Odyle
  Energy limit is per character instead of per server.
- Duplicate shop pets or skins become reward tickets, valid until maintenance 2026-11-25.
- During the transfer: kicked to the title screen, account can't log in, takes ≥1 minute [360].
