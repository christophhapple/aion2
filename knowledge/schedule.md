# Schedule: time-gated content (EU)

Researched 2026-10-10. **No official global schedule exists.** Fixed times come from community trackers
reading the global client [61][62][63]; unverified unless tagged `in-game`. Sources [n]: `sources.md`.

## Clock basics
- **EU server time = Central European local time** (in-game 2026-10-10: clock tooltip shows server time
  equal to local CEST). 21:00 server = 19:00 UTC [61][62][64].
- The clock tooltip also shows a third value, **game time** (the in-world day/night clock), 7 hours
  behind server time (in-game 2026-10-10). Event times are server time, not game time.
- Times below are **server time** = local clock.
- **Daylight saving change 2026-10-25:** the daily reset is fixed at 07:00 UTC (in-game), so locally it
  moves 09:00 → 08:00. Whether event times stay on the local clock or on UTC is **unknown**: verify.
  **Hint (in-game 2026-10-18):** the Season and the Halloween event end at 09:00 CET (08:00 UTC) per their countdowns,
  i.e. at the usual local reset time. So the reset may stay at 09:00 local after the change (unverified).
  **Counter-hint (in-game 2026-10-23):** at Fri 12:07 CEST the weekly recharge countdowns (Daily Dungeon,
  Ascension Trial) showed 4d 20h 52–53min, i.e. Wed 28 Oct 07:00 UTC = **08:00 CET**. So the weekly reset
  looks like it stays on UTC and moves to 08:00 local.
  **Settled (in-game 2026-10-25, after the change):** event times stay on the local clock (Spacetime Rift opened at
  08:00 CET), and the daily reset is **08:00 CET = 07:00 UTC** (Halloween attendance: "Resets daily at 08:00";
  Nightmare "Daily recharge in 23h 57min" at 08:03). In-game windows show times on this server/local clock.
  **Still open:** the 2026-10-18 countdowns put the Season and Halloween end at 08:00 UTC (09:00 CET), but the windows
  show "11/04/2026 08:00" (attendance) and "12/16/2026 08:00" (season items), i.e. 08:00 CET = 07:00 UTC. A fresh
  countdown would settle it.
  **Glitch (in-game 2026-10-25):** the first Nightmare daily recharge after the change (08:00) gave no attempts: still
  0/14 after a relog and a game restart, although the timer rolled over. Watch for this at the next clock change.
- KR/TW schedules differ (e.g. Abyss sieges Wed/Sat in KR). Don't use KR timers such as aion2hub's [61].

**Two pools per counter** (in-game 2026-10-23, tooltips of Shugo keys, Nightmare, Ascension Trial, Daily
Dungeon): the **Default Count** refills on its daily/weekly cycle up to the cap above; tickets and keys
from items go into a separate **Recharge Count**, **cap 30** for all four. The default count is spent
first, so regen keeps running while recharged entries wait. Shown as e.g. `4(+6)/21` = 4 default + 6
recharged. Odyle Energy works the same way, there called **Charged Odyle** (`expeditions.md`).
