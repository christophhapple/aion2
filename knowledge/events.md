# Open-world events

Researched 2026-10-11. Times: `schedule.md`. Sources [n]: `sources.md`. Unverified unless tagged `in-game`.

## Dimensional Invasion

- **When:** every hour at :30 server time; ~3 min to join (timer icon next to the minimap), then the
  round. **10-minute time limit; a round took about 5 min** (in-game 2026-10-11). ~~3 min~~ [102].
  Random field spots in the home regions (Verteron/Altgard) [100].
- **Didn't show up at 15:30 on 2026-10-20** (in-game). No patch, known-issue post or timer change found that
  day (all trackers still say every :30 [61][62][63][352]). Not in a Rift or the Abyss, and checked inside the join
  window, so cause unknown. **Back at 16:30 the same day** (in-game 2026-10-20), so a one-off skip, not a
  schedule change.
- **In a Spacetime Rift or the Abyss** the timer next to the minimap still shows, but greyed out: you can't join
  from there. Teleport back to Verteron within the join window and you can still join (in-game 2026-10-20;
  matches [352]).
- **Who:** solo is fine, no minimum party [100]. Rewards from level 45 [100].
- **Three types, one shared reward table** [100][102]. Waves of mobs across a platform, boss in the
  centre near the end [102]. Beritra Air Raid seen in-game 2026-10-11.

  | Type | Mobs | Boss |
  |---|---|---|
  | Beritra Air Raid | Drakan Air Raiders, Air Raid Warmages, Ferocious Racon | Air Raiders Captain Tetrata |
  | Accursed Sword | Corrupted Drakan forces | Executor of the Magical Sword |
  | Incursion of the Spirits | Earth, Fire and Wind Spirits | Grandios, Spirit Ruler |

- **Scoring:** points from damage and kills over the whole round; the boss is a big share, so keep
  hitting it when it spawns [101][102]. AoE and DPS classes rank higher.
- **Reward picks (contradiction):** top 2 get 4 picks, top 5 get 3 [102] vs. score ≥100 gives 3 picks
  regardless of rank, <100 nothing [103, KR/TW]. Unverified for EU; not important in practice.

### Keys
- Rewards cost a **Dimensional Invasion Reward Key**. +1/day, holds up to 7 [100][102] (both in-game 2026-10-15). **Key count (x/7) is only shown on the Invasion screen inside a running Invasion**; no way to open it from outside (in-game 2026-10-15).
- **Cancelling the card selection keeps the key, but gives no rewards at all** (in-game 2026-10-11).
  So a round without a key is wasted; only join when you'll spend one.
- Refill time: "16:00 server time" [100][102], probably wrong for EU like those sites' daily reset.
  Likely the normal daily reset (07:00 UTC): player's assumption, not checked.
- Key count: no obvious place to see it while no invasion is running (in-game 2026-10-11, tentative). Check the join or reward screen.
- Shared across characters on the server per some guides, account-wide per others (see `schedule.md`).
- One KR wiki mentions a cap of 2 reward claims/day and 14/week [103]: likely KR only.

### Rewards (global client data, level 45–49 bracket [100])
- ~~Common package without a key~~: no rewards without a key (in-game 2026-10-11).
- With a key: Enhance Stone ×700 + ×1,200, Centuryroot Token ×50, Soul Codex (Bound) ×3, Abyss Points
  ×800, plus chance drops [100]. Felt "mediocre, but worth it" (in-game 2026-10-11, amounts not checked).
- Centuryroot Tokens are spent in the **Festival Shop** (growth materials, skins) [100][101].

### Festival Shop (in-game 2026-10-13)
Shugo Festival window → Festival Shop. Tabs: Consumables, Wings, Pets, Artwork, Skins. Consumables, all Bound.
Limits count purchases ("11/15" = 11 bought); non-monthly ones are likely lifetime like the Nightmare shop's (in-game there; inference here):

| Item | Price (tokens) | Limit |
|---|---|---|
| Daevanion Crystal | 400 at "Step 4/4" (price rises in steps) | per character, showed 11/15 |
| Soul Crystal | 50 | per character, **monthly** 30 |
| Stigma Shard | 300 | per character 35 |
| Empathy Candy (pets) | 20 | none shown |
| Radiant Odyle | 1,000 | per character, **monthly** 3 |

No Wisdom Stones. Token sources: Invasion with a key (×50 [100]) and Shugo Festival runs, **~150 per run, varies** (in-game 2026-10-13). So a Stigma Shard ≈ 2 festival runs.
Achievements (Shugo Festival window): per-minigame tiers (I = 1 run, II = 2, III = 3 and the title), "participate 30 times", "Collect 30,000 Centuryroot Tokens" (in-game 2026-10-13).

**So:** worth doing **only with a key**, ~1 per day; ~5 min for maybe ~1,900 stones. Small next to
the Daily Dungeon (6–7k at GS 1100–1500, in-game). Keys bank to 7, so no need to go every day.

## Halloween event (2026-10-14 → 2026-11-04)

Source: mein-mmo news [210], 2026-10-14 (AI-translated from German); **confirmed in-game 2026-10-14** at the event
merchant (quests, coins, shop, login reward). Item names are the article's translation; bracketed mappings are mine.
Global version's first in-game event. No paid requirement mentioned.

- **Currency:** Halloween Pumpkin Coin. Spent at event merchants in the cities (Elyos: Dawn Legion Base
  or Zumion Village; Asmodians: Safe Haven or Nornir Assembly).
- **Login:** 14 days of logging in give 620 coins in total.
- **Weekly quests**, once per week per server each, 235 coins/week in total:

  | Quest | Coins |
  |---|---|
  | Abyss: hunt 10 monsters | 25 |
  | Transcendence: complete 1 | 25 |
  | Expedition: clear a Conquest dungeon | 25 |
  | Ascension Trial ("Ascendance exam"): complete 1 | 25 |
  | Nightmare: complete 1, any level | 25 |
  | Log in 3 times | 30 |
  | Obtain a Unique equipment piece | 20 |
  | Use 5 scrolls (Command Scrolls?) | 20 |
  | Dimensional Invasion: take part once | 20 |
  | Shugo Festival: play one minigame | 20 |

- **Max coins:** 3 weekly resets in the window (Oct 14, 21, 28) × 235 + 620 login ≈ 1,325 (my math, if
  the event ends at the Nov 4 reset).
- **Shop** (Halloween Pumpkin Coin Shop, in-game 2026-10-14). All Bound. Limits marked "weekly" showed
  "Resets in 6d 14h", i.e. the Wednesday reset:

  | Item | Coins | Limit |
  |---|---|---|
  | Special Halloween Chest: skeleton skin + 10,000 Soul Crystals | 250 | per server 1, **once** (no reset shown) |
  | Odyle Energy | 10 | per server 4, weekly |
  | Lower Abyss Rift Stone | 30 | per server 2, weekly |
  | Skin Chest (10 times) | 15 | per server 5, weekly |
  | Resurrection Spiritstone | 2 | per server 10, weekly |
  | Instant Clear Ticket: Daily Dungeon (name cut off) | 3 | per server 7, weekly |
  | Nightmare Dungeon Challenge (ticket, name cut off) | 7 | per server 3, weekly |
  | Shugo Festival Reward Key | 7 | per server 3, weekly |
  | Life Crystal | 2 | per character 20, weekly |
  | Halloween Candy | 2 | per character 10, weekly |
  | Halloween Cookie | 2 | per character 10, weekly |
  | Superior Power Shard | 1 | none shown |

  Buying every weekly limit costs 338 coins, more than one week's quests (235).
- **Candy keys:** key fragments drop in Expeditions and Transcendence; turn them into coloured keys via
  Substance Morph. Candies: red = 20 pet growth boxes, 10 battle scrolls; yellow = 10,000 Abyss Points,
  10 life crystals (yellow in-game 2026-10-18); blue = 4 Odyle Energy, 10 resurrection stones. Each also has 5 Halloween Candy + 5 Cookies.
- **Buff food (5 min):** Candy = +25 Attack, +250 Defense, +300 max stamina, +40% stamina regen.
  Cookie = +500 max HP, +250 max MP, +300 max stamina, +40% stamina regen.
